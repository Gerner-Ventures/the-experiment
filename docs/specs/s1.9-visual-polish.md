# S1.9 — Visual Polish & Deferred Features

Visual polish plus features deferred from S1.3, S1.5, and S1.6.

## Day/Night Cycle (from S1.3) — Implemented

A full day/night cycle system that maps the 6 game phases (`gm_plan → dawn → morning → midday → afternoon → night`) to visual changes on the isometric world.

### Architecture

```
WebSocket phase_change
  → experimentStore.onPhaseChange(msg)
    → experimentStore.currentPhase = phase
      → SimulationView watcher
        → pixiWorldRef.setPhase(phase)
          → DayNightCycle.setPhase(phase)
```

**Layer structure** (all PixiJS — no DOM sky layer):

```
app.stage
  ├─ skyGraphics (z=-1)              Sky gradient (FillGradient)
  ├─ worldContainer (z=0)            Camera-affected content
  │   ├─ IsometricMap (z=0)
  │   ├─ AmbientOverlay (z=1000)     Weather particles
  │   └─ [ColorMatrixFilter]         Brightness tinting
  └─ celestialContainer (z=1)        Screen-space (camera-independent)
      ├─ starContainer               50 individual star Graphics
      ├─ shadowGraphics              Ellipse below sun
      ├─ sunContainer                Sun body + glow + corona rays
      └─ moonContainer               Moon body + crescent + glow
```

### Animation Strategy

| Animation | Tool | Rationale |
|-----------|------|-----------|
| Phase transitions (arc, filter, sky, crossfade) | GSAP | Orchestrated: coordinates multiple properties over 2s with `power2.inOut` easing |
| Night→dawn wrap | GSAP timeline | Sequenced: fade-out-moon → reset arc → fade-in-sun |
| Star twinkling | PixiJS Ticker | Continuous per-frame alpha oscillation, no start/end |
| Corona ray shimmer | PixiJS Ticker | Continuous per-frame length oscillation |
| Digital orb pulse (Matrix) | PixiJS Ticker | Continuous alpha oscillation |
| Demo mode auto-cycle | PixiJS Ticker | Timer-based phase cycling every ~10s |

### GSAP Lifecycle

All tweens tracked in `activeTweens[]` array. On every `setPhase()` call, `killActiveTweens()` kills all in-progress tweens before creating new ones. `destroy()` kills everything + removes the tint filter from `worldContainer.filters`.

### Theme Support

4 themes with distinct palettes defined in `config/day-night-palettes.ts`:

| Theme | Dawn Sky | Midday Sky | Night Sky | Celestial |
|-------|----------|------------|-----------|-----------|
| Island | `#ff9966→#ffcc88` | `#87ceeb→#e0f0ff` | `#0a1428→#1a2040` | Warm yellow sun, blue-white moon |
| Matrix | `#001100→#002200` | `#000d00→#001a00` | `#000400→#000800` | Pulsing green digital orb |
| Arena | `#cc7744→#ddaa66` | `#f0e8d0→#fffff0` | `#0f0a1e→#1a1030` | White sun, cream moon |
| 1984 | `#332211→#553322` | `#555544→#887766` | `#050308→#0a0510` | Dim orange sun, faint moon |

### Key Design Decisions

- **`gm_plan` is a no-op** — meta-phase inherits previous visual state
- **Sky gradient is PixiJS-native** — uses `FillGradient` on `app.stage`, not DOM
- **Stars are individual Graphics** — twinkle via alpha, no per-frame geometry rebuild
- **Sun arc uses MotionPathPlugin** — paused tween with `progress` control for arbitrary phase jumps
- **Star seeds are normalized** — resize scales proportionally, no re-randomization
- **Moon crescent color derived from theme** — uses night sky `skyTop` color per palette

### Demo Mode

When `demoMode` is true (no backend), the cycle auto-advances through all phases every 10 seconds. Triggered via `PixiWorld.vue → world.startDemoCycle()`.
